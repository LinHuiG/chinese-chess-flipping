CyberRoom Windows native media components

This distribution embeds unmodified MSYS2 mingw64 libmpv 0.41.0-6 and the
runtime libraries identified in msys2-package-lock.json. These components
are authored by their respective upstream developers, not CyberRoom.
No standalone mpv or FFmpeg executable is launched.

Pinned source and build material for this exact native distribution:
https://github.com/LinHuiG/chinese-chess-flipping/releases/tag/media-mpv-msys2-fb232a877695
The source archive includes the upstream source packages, PKGBUILD recipes
and patches, binary build records, incorporated static/header dependencies,
and the checksummed Rust crate sources used by retained Cargo lockfiles.
The release must be available before this native executable is published.

Upstream binary/source package repositories:
https://repo.msys2.org/mingw/mingw64/
https://repo.msys2.org/mingw/sources/
Application integration source and installation/build scripts:
https://github.com/LinHuiG/chinese-chess-flipping
