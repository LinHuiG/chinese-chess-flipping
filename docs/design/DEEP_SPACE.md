# 深空冷域视觉方案与素材

2026-10-15。用户选择 D「深空冷域」，覆盖大厅、翻棋、黄金矿工、电影厅和片库。采用石墨黑、蓝黑金属、冷白文字和少量冰青强调，减少大圆角、暖色卡通与装饰性霓虹。界面仍使用真实的六人电影厅、两人翻棋、二至三人矿工规则。

## 设计与实现

- [方向图](deep-space-direction.png)：用于确认视觉方向，图中文字和示意导航不作为功能契约。
- `server/src/main/resources/web/theme.css`：大厅、通用弹窗、翻棋、矿工状态与商店。
- `style.css` 与 `index.html`：影院主屏、独立片源设置和独立片库；海报、简介、按季集浏览、真实季集编号和排序。
- `miner-view.js`：背景与透明图集绘制，保留原世界坐标、碰撞、插值、缓存和像素预算；角色根据横屏上方空间缩放，矿石保持比例。

## 播放器交互参考

用户追加要求参考开源 Emby 播放器。采用 [Jellyfin Web 官方项目](https://github.com/jellyfin/jellyfin-web) 的交互思路：常用播放操作与展开的播放设置分开，画质、倍速、音轨和字幕可发现，轨道显示语言和名称。代码按本项目共享界面及原生桥独立实现，没有复制该项目源码或商标素材。参考 [播放管理实现](https://github.com/jellyfin/jellyfin-web/blob/master/src/components/playback/playbackmanager.js) 与 [项目许可证](https://github.com/jellyfin/jellyfin-web/blob/master/LICENSE)。

房主控制播放时间和倍速；成员独立选择清晰度、音轨、字幕、音量。Emby 的 [PlaybackInfo API](https://dev.emby.media/reference/RestAPI/MediaInfoService/postItemsByIdPlaybackinfo.html) 协商必须检查实际返回能力，不把可选控件当作服务一定具备转码能力。文本字幕读取完整 WebVTT，按片内绝对时间匹配，不受 HLS 起始时间影响；格式依据 [WebVTT 规范](https://www.w3.org/TR/webvtt1/)，本项目首版以纯文本显示，忽略字幕内的排版样式。
