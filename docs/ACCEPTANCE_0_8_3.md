# 0.8.3 深空冷域与电影播放器验收

本次版本为 0.8.3，Android versionCode 16。用户最新确认第三方 HTTP 片源没有管理权限，并明确“不再提问，修不好先这一版发布然后部署然后关机”。因此已知片源限制不再阻塞发布；客户端检查、正式构建和部署复验结果见下文。本记录区分客户端检查通过与真实片源限制，实际发布和部署结果已补记。

## 已实现

- 全局石墨黑、冰青色界面；矿工矿洞背景、机械矿工和物品图集，兼顾手机长屏、横屏与全屏。物品图集进入矿工时才加载，大厅矿工卡片使用矿洞背景。
- Emby 片源设置与选片分开，海报、简介、详情、电影/电视剧筛选、剧/季/集浏览及跨分页数值排序。
- 房主统一播放、暂停、进度和六档倍速；各端独立画质、音轨、字幕、音量、静音、失败重试。全屏保留控制和选择弹层。
- Windows 内嵌 libmpv，原画支持浏览器不支持的 E-AC-3；按真实媒体索引切换音轨和字幕，不重新协商或重置进度。按散列解包加载，随包保留许可证，见 [组件说明](WINDOWS_NATIVE_MEDIA.md)。
- Android 修复独立控制指令、电影与麦克风音频焦点冲突、原生视频负坐标吸顶；字幕按本地播放时钟和转码偏移显示。
- HTTPS 网页可用经同服校验的 HTTPS 片源别名。播放终止错误不会被房主同步不断清除和重新拉流；每片最多一次自动兼容回退，仍可显式重试。

## 用户真实片源

1. 《小学风云 · S03E10 · “艾娃节”回归》（128223）：此前原型 PC 的 H.264 + E-AC-3 通过；最终 MSYS2 包未完成真实片源复验。WASAPI 实际输出为两声道 48 kHz，诊断记录 156,672 个 PCM 样本、峰值约 0.484；首帧、1.5 倍速、音量/静音、暂停后跳转 60 秒、内嵌中文字幕选择与关闭、全屏控件通过。Computer Use 直接观察到该片画面。
2. 同片网页：浏览器不支持该 E-AC-3 音轨；Emby PlaybackInfo 不给兼容转码 URL。官方 HLS 接口能返回清单，但 TS 分片超时或 HTTP 500。因此该片在网页上的播放仍未通过，客户端没有权限修复 Emby 的转码执行环境。
3. 兼容 AAC 剧集（124642）：网页房主与晚加入成员两人通过，均有 1080p 画面和非零音频解码，成员从约 4 秒加入并正常继续播放。三路取流时第三路云存储响应触发 `ERR_BLOCKED_BY_ORB`，发生在元数据/跳转之前；账号报告 `SimultaneousStreamLimit=0`，具体上游策略仍不明，不能据此宣称“账号只支持两人”或六路片源容量通过。
4. 最新官方 Emby 网页对照：独立默认 Edge 登录、打开同片详情并点击播放，18 秒内视频推进约 16.52 秒、1080p、视频解码字节非零，未静音而音频解码字节为 0；其自身同样没有得到转码 URL，直接取原始 E-AC-3 文件。按其 query/body 请求格式重试协商仍未获得转码地址；只转换音轨、复制视频的 HLS 首段也超时，停止和会话清理成功。这缩小了差异范围，但具体上游根因仍须 Emby 转码日志确认。
5. Android 同片原生直流能力检查：真实首帧和截图通过，但音轨不支持/未选中，音频缓冲、PCM 帧和峰值均为 0；独立平台探针确认该 API 37 模拟器无 E-AC-3 解码器。此项绕过共享片源协商以隔离原生能力，生产仍走 AAC 转码；不能将有画面说成完整播放通过，也不推广到所有 Android。有效结果在 `android_client/app/build/real-android-media-check/`，脚本为 `android_client/scripts/real-media-check.cjs`；已修正初次隔离脚本被断线清理影响的问题，旧结果不采用。会话和测试设备已清理。

未关闭浏览器安全限制、未更改 Emby 管理配置。真人听感、外放回声、蓝牙、多厂商 Android、公网 NAT 和长期六人播放容量不由本地模拟器及软件回归替代。

官方网页请求、有限音轨转码实验和所需服务端日志详见 [Emby 播放对照诊断](EMBY_PLAYBACK_DIAGNOSIS_0_8_3.md)。
