# 0.9.0 插件平台验收（本地完成，发布待核验）

本次用户授权开发、全量代码审查、验证后提交发布、通知原部署线程部署第一台 fqgame.tdcode.tech，最后关机。第二台不操作。下面仅记录已经执行的检查，发布结果后续补齐。

- 三个业务目录和 SDK 已拆分，核心没有内置游戏/电影厅载荷。原生 APK/EXE 独立安装，房间绑定精确发布及支持平台。
- 宿主/电影厅 Windows 单元分别 10 / 23 项通过；另 1 项需外部媒体诊断输入而忽略，实际播放用原生 UI 验收覆盖。
- JavaScript 房间/规则/恢复/成员路由 20 组通过；插件负向权限/签名、字幕、原生播放、跳转、慢加载竞态、存档、采集时间和桥接队列检查通过。
- Android 构建及单元通过；首次全工程 lint 找到独立组件缺少麦克风清单声明，修正后全工程 lint 通过（0 errors；保留依赖新版本/备份/图标等非阻塞 warnings）。主工程 7 项 JVM 含真实 Rust 互通无跳过，组件 16 项 JVM。API 37 模拟器 Keystore 加密、篡改、非导出密钥和删除检查通过。
- 审查修复：原生事件代次、退出等待存档、过期成员快照、新授权异步发送时序、未声明网络权限的外部资源、输入/HTTP/IPC 大小界限、旧数据迁移、DLL 长路径和选片保存期间退出竞态。
- 初轮浏览器翻棋安装/补装/开局/刷新恢复/解散及父存储隔离通过。Windows 和 Android 电影厅独立组件实际首帧、Web 联机、无片源弹幕、跳转、全屏和退出通过；审查后重验通过。Android 首次点击被软键盘布局变化影响，移焦后相同 UI 流程通过，没有改为直接调用业务接口。

尚未将这些检查称为真实多厂商手机、真人回声/蓝牙、长期弱网、全部第三方 Emby 或任意第三方原生插件的兼容保证。当前原生插件是审核信任代码；Android 同进程加载，Windows 独立进程不降权。新权限二次同意按用户决定暂不实现。

- 最终 Web 实际检查：三种尺寸矿工、旧存档重绑定、3 秒测试存档商店到期进入下一关、点击放爪、全屏、持久保存；宿主麦克风采集到另一网页 AudioWorklet 实际收到播放帧、关麦释放；HLS 插件自带依赖/worker、转码后视频进度、房主保存/恢复倍速及删除通过。完整 20 秒商店引擎规则由单元检查覆盖。
- Windows 宿主和组件 Clippy `-D warnings` 通过。检查中的冗余类型/无用转换已清理。Rust 原生编解码/播放实现保留 0.8.4 修复。
- 发布工作流 YAML 解析通过；签名目录和全部载荷的大小/SHA-256 检查通过。旧发布归档使用持久 GitHub Release；Android 组件依据源指纹复用，拒绝覆盖已有包名的不同二进制。
- 当前维护的 UI 验收入口为 `plugin-smoke.cjs`、`plugin-features-smoke.cjs`、`plugin-native-smoke.cjs`。历史 0.8.x 直接页内模块脚本仅供旧版本记录，不能用于新插件架构。CI 使用已迁移的所有单元/契约脚本。
