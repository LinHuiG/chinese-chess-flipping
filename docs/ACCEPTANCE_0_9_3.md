## 实现与版本

- 选集 UI 明确显示“选集”，请求返回与点击均检查房间、片源、播放 epoch 和房主身份；过期结果丢弃，错误可重试，当前集可定位，普通与全屏共用列表。
- 当前影片下增加“诊断日志”入口，提供只读文本、刷新和全选复制；原生视频沿用 dialog 遮挡处理。诊断内容由播放层生成并脱敏。
- 旧存档缺失 seriesId 时通过当前条目详情恢复所属电视剧；重新登录恢复保留季集元数据。选集入口不再因旧存档缺字段直接消失。
- Windows Mailbox 合并 load 与字幕 cues 时，旧实现先设置 cues 再清空，导致字幕请求成功却不显示。修正为先清旧片，再应用同批字幕；Mailbox 与播放器拒绝旧 playbackId 的迟到操作。
- 共享字幕异步操作在原生调用前捕获所有权，所有回调校验 generation/字幕操作序号/session/access；字幕命令携带 playbackId。单份已解析字幕缓存避免同片跳转/重载反复提取，授权变化隔离缓存；换集按语言、强制标记、格式及外部属性匹配，避免复用错误索引。
- 日志上限 300 条，字段白名单，记录播放协商、模式、字幕请求/完成/错误/选轨及会话关联号。导出包含当前播放/字幕状态；不记录 URL、授权头、token、字幕正文。
- 宿主/服务端 0.9.3，Android code21；翻棋、矿工、电影厅市场版本 1.0.3；Android 电影厅包名和入口统一 `com.cyberroom.watch.v103`。旧市场记录保留不变，升级后更新插件并新建房间。

### Windows 字幕竞态专项（2026-10-23）

- 原生队列会合并新片 `url` 与后到的 `subtitleCues`。旧实现先安装 cues，随后在同一命令的新片分支清空 cues；已改为先清旧字幕、再安装当前合并命令的新字幕。新加载也重置旧字幕时间偏移。
