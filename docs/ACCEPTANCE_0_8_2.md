# 0.8.2 矿工手机体验与电影厅社交修复

2026-10-14。用户要求修改、统一测试后发布，并通知现有“部署线程”部署第一台。本次不包含关机。用户补充通话问题第二次进入可恢复，按偶发初始化故障验收，不能用一次收发成功代替首次/重入检查。

## 修复内容

- 矿工摆爪基础角速度由 0.84 调至 0.60，出钩由 440 调至 280，基础回收由 380 调至 240；重量、汽水和卷扬机的效果继续生效。首关 80 秒改为 110 秒，后期最低 52 秒改为 72 秒，存档中正在进行的剩余时间不重置。
- 手机游戏区域使用可用视口高度，竖屏展开矿场，横屏将积分和操作置于侧栏；商店有独立滚动区。矿场位置投影适配视口，矿石/角色图形保持比例，联机世界坐标与房主规则不变。提供全屏按钮，转屏保留全屏与房间；系统 Back 先退出全屏。
- 点击矿场或空格出钩；移动手势、暂停、爪子忙碌、弹窗和请求处理中不误发。炸药、暂停、保存等按钮保持独立，增加键盘 Enter 和辅助操作入口。
- 静态矿石和背景缓存，动态物体使用图像缓存；接收快照时冻结显示目标并插值，避免房主可变数组和每帧大量临时对象；限制画布像素和粒子数量，原生后台停止矿工绘制。
- Android `voiceStatus` 带同一个 `suggestedDirectLimit` 时，旧客户端会不断调用 `configure` 再产生 `voiceStatus`，形成反馈循环。现在仅在值变化时更新配置，减少主线程和桥调用负担。
- 浏览器在手势调用栈内立即恢复 AudioContext，加载 worklet 期间的后续手势仍可恢复；关闭、重入及挂起状态不沿用旧初始化和陈旧音频时钟。Android 闭麦收听使用媒体路由，开麦切换后重建输出轨道。
- 原生弹幕覆盖层独立于 ExoPlayer 和 Emby 片源；未选片也能收发弹幕与通话。原生正文上限为昵称加 200 字正文预留空间，无片源时明确显示“开启语音收听”。

## 边界与发布

API 37 模拟器的实际采集声音很弱，已证明采集/传输/解码/输出路径与非零 PCM 写入，未宣称真人听感、外放回声、蓝牙、多厂商 Android 或复杂公网 NAT 全部验证。浏览器仍需要手势授权播放声音，不能绕过其自动播放策略。
