# 全局深色界面与翻棋改进（本地）

日期：2026-10-26。用户要求全局检查界面并直接修复，参考苹果深色设计，同时完成此前提出的棋盘抖动、单屏布局、星纹居中、走子动画、投降、请求和棋及加入房间按钮问题。

本次只修改当前工作区；未提交、推送、发布、部署或关机。初轮 UI 实现由主线程完成，随后按用户明确授权安排子代理独立复查 UI，并行处理 [矿工卡顿与抓取偏移](MINER_PERFORMANCE_2026_10_26.md)；未使用 dsh。线上仍为 0.9.3；宿主版本与插件清单版本暂未改动。后续发布需要更新宿主资源，并重新构建三个插件的共享界面，房间继续绑定固定发布。

## 已完成

- 宿主大厅、市场、设置、建房、密码与确认弹窗，以及插件等候室、矿工、电影厅和片源/片库/诊断弹窗，统一中性深色背景、分层表面、系统字体、蓝色主操作、圆角、焦点和输入控件。设计参考 [Apple Dark Mode](https://developer.apple.com/design/human-interface-guidelines/dark-mode) 的深色表面与层级原则。
- 手机大厅已安装插件改为紧凑列表，保留封面与创建入口；电脑继续使用卡片。等候房间修复密码按钮与时间选项相贴的问题，小屏始终保留规则入口。
- 加入密码弹窗的输入框与操作区分开，取消/加入同高且留出间距。插件卸载、入房前安装改用同主题确认框；返回键遵循取消事件，避免直接关闭时丢失确认结果或忽略操作中的关闭限制。
- 翻棋使用固定高度的标题、单行状态和成员栏，棋盘按可用宽高缩放。移除重复回合提示和长说明；轮换、颜色确定、结果与重开入口不改变棋盘位置。普通窗口、宿主 iframe 和全屏使用同一布局。
- 短横屏把翻棋信息移至右侧固定栏：844×322 下棋盘高度由约 182 px 提升到 306 px。短横屏片库压缩顶部标题、工具栏和路径，移除搜索表单遗留间距，保证首张海报可见。
- 暗棋四角星改成对称 CSS 图形，中心不依赖字体基线。棋子保持圆形；走子/吃子在原格与目标格之间移动 280 ms，翻棋保留翻面。只播放连续新一步的动效，重复快照不重新播放；关闭动画或系统减少动态效果时不播放移动动画。
- 翻棋“更多”内新增投降确认和请求和棋；对方同意才和棋，拒绝提示请求者。等待期间计时继续，合法行动使请求失效，同一步每人最多请求一次。结果、重新开局和成员退出清理请求。协议和时间边界见 [棋局规则](GAME_RULES.md#61-投降与请求和棋)。
- 和棋请求/回复按当前对局关联，迟到旧局结果不弹新局提示或误解锁按钮。离线时收起请求弹窗，恢复后重新显示；返回键优先取消当前有焦点的顶层弹窗。
