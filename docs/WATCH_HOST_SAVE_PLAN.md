# 电影厅房主存档方案

2026-10-15 更新：用户明确要求各端房主本地自动保存片源和播放设置，每隔几秒及退出时保存，下次恢复。共享客户端与 Windows / Android 安全存储已实现并本地打包；实际验证边界和发布状态以 PROJECT_STATUS.md 为准。下文保留原方案范围，未实现的扩展明确列出。

## 当前实现范围

- 每台设备保存最近一次由本机房主登录的片源、选中影片/剧集和进度；每 5 秒保存，暂停/跳转控制停止变化 300ms 后补存，音轨/字幕/画质调整、退后台与退出补存。退出等待原生写入；网页 pagehide 同步写入浏览器存储。
- 新建电影厅自动恢复；仍有效的旧房间先恢复原成员关系和影片，使用新播放器会话。恢复始终暂停，点击播放继续，离线时间不计入进度。
- 保存倍速、画质、音量、静音、所选音轨和字幕（含烧录/兼容选择）；HLS 保存完整时间线的位置，重新协商播放 URL。只保留最新一部的记录，原方案多片源管理与多影片历史列表尚未实现。
- 连接表单提供“在本机记住片源和播放设置”，网页明确说明授权保存在此浏览器；片源设置可删除本机存档，当前房间继续观看，删除后不会被定时器或迟到请求重新写回。
- Windows 使用当前用户 DPAPI 加密并原子替换文件；Android 使用 Keystore AES/GCM 和应用私有非备份目录；不保存原始密码。成员收到的授权不进入个人存档。
- 授权失效/片源暂时不可用保留记录，重新连接同一地址与用户后恢复进度。校验与存储错误不输出授权正文。实际验收见 [0.8.4 记录](ACCEPTANCE_0_8_4.md)。

## 用户流程

2026-10-15 用户补充确认：当前房主保存的内容不足，Emby 数据源和片源配置都未完整保存。目标是房主重新创建电影厅后，直接读取本机存档，配置与上次解散房间时一致；旧成员不恢复。当前最近片源和完整播放设置已按上方范围实现并验收；多数据源列表与历史管理仍待扩展，不能只保存地址或要求房主每次重新选择、填写片源。

房主首次连接片源时完成本机保存授权；影院保留独立的 Emby 数据源、片源设置和片库。下次建电影厅自动载入上次使用的数据源、片源配置及其他房主配置，片库展示“继续观看”，明确影片/剧集名与上次进度。恢复后先暂停，由房主开始全房播放，避免新建房间自动出声。

设置中提供“退出此片源”“删除此片源及观看记录”和独立清除历史。授权过期时只要求重新登录，保留观看进度；影片下架时提示重新选片，不丢掉其他记录。

## 保存范围

| 数据 | 保存方式 |
| --- | --- |
| 房主配置 | 完整保存上次解散时的房主配置，包括 Emby 数据源列表、当前选中的数据源及其片源配置；实现时核对全部可配置项，避免仅保存地址或观看进度 |
| 片源 | 用户自定名称、基础地址、服务器标识（可取得时）、用户标识和访问令牌；不保存原始密码 |
| 观看记录 | 片源标识、影片 ID、片名、剧名及季集编号、实际播放秒数、总时长、最后观看时间；以片源与影片组合为键，保留最近有限条记录 |
| 偏好 | 本机音量、清晰度偏好；房主恢复时可带上所选倍速，但全房开始仍需主动操作 |
| 不保存 | 旧房间号、成员列表、麦克风开启状态、播放中的 URL、转码会话及短期票据 |

仅保存房主自己登录的片源，成员收到的房间授权不自动转为自己的长期片源。第一阶段仅本机，不增加服务端账号与云同步。

## 时机与恢复

每五秒保存实际已播放位置，暂停、提交拖动、换片、退出与进入后台时补存。以播放器时间加转码起点计算完整位置，不把关闭应用期间的墙钟时间算作播放。

数据源和片源配置变更时保存，房主主动解散前补存最终配置，避免房间清理先清空待保存内容。重新建房时自动读取本地存档；新房间仅有房主，旧成员、旧准入和通信会话不随配置恢复。

仍有效的房间先走原房间恢复；原房间已解散时创建新房间，使用新的播放代次和成员准入。不能复用旧房间或 HLS 会话来冒充恢复。片源令牌有效性由重新取片确认，失败时显示重新登录。

Android 用系统 Keystore 保护本机保存密钥，Windows 使用当前用户范围的 DPAPI 保护令牌；网页须显式选择记住，说明同一浏览器配置下保存授权，不声称普通 localStorage 已加密。原始密码只用于登录请求。[Android Keystore](https://developer.android.com/privacy-and-security/keystore)、[Windows DPAPI](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata) 为实现参考。

## 验收重点

配置 Emby 数据源和片源后解散，再创建电影厅，无需重新填写或选择即可恢复上次配置；修改配置后重复此流程，以最后一次解散时的配置为准。重启客户端后再建房也应恢复本机存档；新房间仅含房主，旧成员须重新加入。这些基础恢复目标已在 0.8.4 验收；多数据源与多影片历史仍按上方边界处理。

关闭后重开、退出再建房、同片源多影片、连续剧换集、拖动后保存、HLS 非零起点、无时长条目、令牌失效与影片下架；普通成员不持久化共享授权，退出/删除后令牌不可再由旧异步请求写回。不得在日志、截图、导出文件或仓库中保存密码与令牌。
