# 0.9.4 验收与发布记录

更新日期：2026-10-26。用户已授权打包发布，正式构建与发布进行中。

## 范围与版本

- 统一宿主与共享插件深色界面，优化手机大厅、加入房间按钮、确认框及横竖屏空间。
- 翻棋固定单屏布局、缩短提示防止棋盘抖动、居中星纹、走子动画，增加投降及需对方同意的请求和棋。
- 黄金矿工统一模拟与显示时钟，修复快照抖动下的停顿追赶、后台恢复及运动时间丢失；减少重复 HUD 写入和无效往返；抓取物与爪心使用同一锚点。
- 宿主/服务端 0.9.4，Android code22；三个插件 1.0.4。电影厅原生 Android 源码未改，继续复用不可变 v103 组件；新市场须保留全部历史发布。
- 本次授权提交、推送和发布；未要求远程部署、通知部署线程或关机。多子代理已完成分工及复核，未使用 dsh。

## 本地已完成

- 共享客户端 21 组、矿工模拟 3 组、运动插值/暖机/生命周期回归、原生事件转发与弹窗测试通过。
- 翻棋七尺寸及四尺寸宿主 iframe/全屏检查、大厅/播放器和共享等候室/矿工/电影厅四尺寸检查通过；真实 Canvas 抓取锚点误差小于 0.01 backing pixel。
- 三插件共 9 个平台脚本构建通过，变更 JS 语法及暂存区空白检查通过。
- 本机无头 Edge 抖动快照测量中，手机尺寸自由摆动冻结帧 39.18%→0%，CPU 6× 场景 39.39%→0%。不是 Android 真机、GPU 或公网 FPS 验证。
- 详细证据及本地截图/报告位置见 [UI 验收](UI_REVIEW_2026_10_26.md) 与 [矿工修复](MINER_PERFORMANCE_2026_10_26.md)。
