# 0.9.1 验收与发布记录

2026-10-16。用户明确授权修复后发布 GitHub，通知现有部署线程部署第一台。无第二台操作或关机授权。

## 改动

电影厅转码 URL 的 StartTimeTicks 与实际播放偏移一致，修复切换 1080p 和继续跳转从头播放。全屏 iframe 权限、Android 横屏、网页及原生视频控制条隐藏/唤出、前进 30 秒/后退 10 秒、房主桌面快捷键与长按操作、网页播放常亮；Safari 优先支持完整元素全屏，不支持时使用系统视频全屏，系统操作接入房主同步。大厅、加入房间按钮与三插件封面统一深空深色。跨端下载进度和按散列断点续传，服务端 Range 支持。

宿主版本 0.9.1，Android code 19，三插件 1.0.1。保留旧插件精确发布；旧房间不会自动切换代码。使用新修复需升级宿主、安装新插件并重建房间。

## 检查

- `watch-quality-native-test.mjs`：真实无窗口静音 libmpv 房主、真实后台 Edge 成员，原画 60 秒→1080p→90→30→60 秒，两端继续解码；实际请求起点核对。房间状态通过测试适配器传递，非原生 TCP 客户端联机验收。
- `plugin-features-smoke.cjs`：本地真实服务端与签名插件包，两网页矿工恢复/下一关/全屏、语音帧/设备释放、电影厅 HLS 首帧/成员播放/设置保存和恢复。Emby 是受控本地片源。
- `ui-player-smoke.cjs`：桌面和横竖屏布局、插件封面、安装进度、键盘/长按/恢复/输入隔离、全屏自动隐藏与唤出、真实 opaque iframe 全屏和 Wake Lock；Safari 原生全屏入口仅 API 模拟。
- Web 下载中断/续传/200 回退/错误范围；Windows 真实 TCP 下载中断续传及 SHA-256 通过。常亮播放、暂停、后台、返回、延迟授权、拒绝及恢复通过。
- 服务端 11 项通过，Windows 宿主 11 项通过，电影厅原生 23 项通过（专用测试另行驱动）。Android assembleDebug、JVM 测试通过。三个插件 bundle、开发市场签名及 11 份载荷校验通过。
- 播放源安全、seek 代次、异步载入竞争、插件权限边界等现有针对性回归通过。下载/常亮测试已加入 CI。
- 用户片源只读核验：Emby 4.10.1.0；HTTP 与 HTTPS 入口服务标识一致；HTTPS/CORS 接受 opaque Origin null；账号允许视频和音频转码。不归档账号、密码或访问令牌。
- 真实 Emby 通过新插件 opaque iframe 登录并读取片库通过，未启动实际片源转码，不计作真实片源首帧验收。
