## 实现选择（不是新增业务规则）

- 房间变更在服务端统一串行化；每连接的加密输出由该连接的 Netty EventLoop 顺序执行。
- 房主处理准备、计时设置、走棋和正常胜负；服务端独立处理退出和断线。
- 等待页初始每步时间为 60 秒，可选 30、60、90 秒和无限。
- 用户补充要求：大厅、等待页和棋局右上角均显示规则按钮；左右分别显示红黑阵亡棋子，按将士象车马炮兵排列、灰显/点亮及右下角红色数量角标。
- 用户要求优先降低服务端内存和 CPU，采用小型 Netty 堆缓冲池、有限请求/输出队列、到期心跳检查、游标分页和按状态变化同步。
- 房主使用单调时钟，以收到并处理动作时的期限裁决；终端倒计时只作展示。
- Android 使用持续连接服务及常驻通知维持用户主动建立的游戏会话，后台不新建连接；不承诺厂商系统不会终止进程。
